# AI prompt history

This file records the prompts sent to AI tools during this project. The project was developed in one Codex conversation. The full conversation remains available in the working session. Responses are not reproduced here because the guidelines require prompts and make responses optional.

## Prompt 1

Read the supplied YottaFlex problem statement and explain exactly what must be built, including every data, workflow, validation, export, edge-case, reproducibility, and submission requirement.

## Prompt 2

Build the challenge end to end inside the `syright` workspace. Cover the synthetic data generator, workflow, validation, exports, documentation, and a working local interface.

## Prompt 3

Audit the implementation against the original problem statement. Fix generator bugs, verify the required baseline coverage and anomaly fixtures, check SQL/CSV/JSON parity, and verify reproducibility.

## Prompt 4

Redesign the interface professionally, add search/filter/sort/pagination, expose decision evidence and disbursement controls, and make the workflow usable in a browser.

## Prompt 5

Review the Candidate Project Submission Guidelines and Candidate FAQ PDFs completely. Identify the submission requirements, AI disclosure requirements, repository rules, individual-work requirements, limitations, and anything missing from the build.

## Prompt 6

Make the project end to end and ready for submission. Add explicit actor workspaces, verify all requirements, improve the UI, and add the required submission documentation.

## AI tool disclosure

AI was used for implementation scaffolding, code review, test design, UI critique, and requirement mapping. The implementation was reviewed and validated locally by running the generator, restoring the SQL export, comparing CSV and JSON exports, running automated tests, exercising the HTTP workflow, and checking desktop and mobile screenshots. The final design rules, policy thresholds, data model, anomaly construction, validation logic, and limitations were reviewed as part of the project build.

No external AI model is part of the submitted application. The running application uses Python's standard library and SQLite only. This avoids requiring credentials, paid services, network access, or a hosted model for evaluation.

## Limitations of this record

The connected coding environment does not expose a machine-readable transcript export for every intermediate tool response. This file records the user prompts available in the working conversation and states that limitation plainly. No hidden or fabricated prompts are added.
